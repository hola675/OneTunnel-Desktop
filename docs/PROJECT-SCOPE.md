# Project scope

## CURRENT

- Tauri 2 shell and React + TypeScript + Vite frontend.
- Disconnected initial UI with Connect disabled.
- Diagnostic `get_app_info` IPC contract.
- Architecture, scope, development, and roadmap documentation.

## PLANNED

- Xray SOCKS engine and VLESS + Reality connection flow.
- 1VPN Free catalog and Premium account integration.
- Connection controls, server selection, settings, diagnostics, and real traffic statistics.
- Packaging and final validation.

## OUT OF SCOPE

For F0: all VPN connectivity, 1VPN API/authentication, Xray runtime, SOCKS listener, benchmarks, traffic counters, retries, installer, and auto-updater.

For the product architecture: Wintun, tun2socks, wstunnel, relay, system VPN, Windows route/DNS/firewall changes, corporate proxy integration, and Proxifier automation or configuration changes.
